# pchyme

**pchyme** generates short wind-chime-like jingles based on text.

Note (Apr 2025): I haven’t touched this project in 10 years, but it’s
theoretically still useful. If you’re interested in using it, let me
know if you need any help getting it up and running!

## Demo sounds

You can listen to [sample jingles] produced with each of the six
included instruments.
